# Sicurezza

Questa repository contiene uno starter dimostrativo. Al momento non gestisce account, ruoli, documenti riservati o richieste AI reali.

## Prima di usare dati reali
- Configurare autenticazione forte e autorizzazione per ogni risorsa.
- Non inserire segreti nel browser, nel repository o nei log.
- Usare un backend separato con segreti in variabili d'ambiente gestite dal provider.
- Definire retention, cancellazione, backup cifrati e accessi minimi.
- Effettuare valutazione privacy e test di sicurezza indipendenti.
- Non trattare dati sindacali o dati personali tramite questa demo.
- Per contenuti normativi, mostrare fonte, data di verifica e versione; bloccare risposte prive di fonte affidabile.

Per segnalazioni di sicurezza, non pubblicare credenziali o dati personali in issue pubbliche.
